# 📊 Data Professional Survey Dashboard (Power BI)

## 📌 Project Overview
This Power BI dashboard analyzes survey data from data professionals to understand salary trends, job roles, programming preferences, and work-life balance satisfaction.

---

## 🎯 Objectives
- Analyze average salary by job title
- Understand country-wise distribution of survey takers
- Evaluate work-life balance satisfaction
- Analyze difficulty level of breaking into data
- Identify favorite programming languages

---

## 📊 Key Metrics
- 👥 Total Survey Takers: 630
- 💰 Salary Insights by Role
- 😊 Work-Life Balance Score: 5.74
- 💵 Happiness with Salary Score: 4.27
